# Durva Fincorp — Website

Static one-page site for Durva Fincorp, served by GitHub Pages at
**https://durvafincorp.cloud**

## Files

| File | Purpose |
|---|---|
| `index.html` | The entire site — CSS and JS are inline, no build step |
| `logo.png` | 640×640, transparent background |
| `favicon.png` | 64×64 browser tab icon |
| `CNAME` | Binds the custom domain to Pages — do not delete |
| `.nojekyll` | Stops Pages processing the files through Jekyll |

## Updating

Edit `index.html`, then:

    git add -A
    git commit -m "describe the change"
    git push

Pages redeploys automatically within a minute or two of the push.
